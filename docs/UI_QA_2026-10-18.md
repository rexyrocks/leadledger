## Changes made

- Append the message gate panel without replacing the draft controls, preserving their input/click handlers.
- Disable extraction when no source is selected.
- Align the attention filter with the attention metric.
- Version the frontend script URL so cached browsers receive the fixes.

## Evidence and limits

- Synthetic lead-15 was edited, approved, simulated-sent, then given delivered/replied/bounced outcomes to exercise the buttons. Final outcome is bounced; an attempted repeat send was blocked.
- Synthetic lead-20 received a fail-closed unavailable-checker report, then was opted out. Existing records and their history were preserved.
- These approvals are automated UI test actions, not independent human review.
- The complete live-model discover → verify → generate sequence could not be validated while the GPU was offline. No fixture fallback was enabled.
- The conditional network-interruption Retry button was not triggered in this browser pass. Automated backend idempotency coverage is separate from browser retry validation.
- Swagger renders the frozen contract's localhost server URL; the docs link was checked, not its Try it out requests from the public domain.
- Regression checks after the draft/source fixes: 76 tests passed; all 24 contract examples and message hash vector passed. Final attention-filter behavior was checked in the browser; JavaScript syntax and diff checks passed.
