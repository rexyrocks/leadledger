FOLLOW THE EVIDENCE

A demo you can inspect.

Choose an existing synthetic example. This guide does not reset the graph or run actions for you.

  1. Discover a permitted snapshot and inspect the evidence.
  2. Verify the contact. Check the execution label and supporting quotes.
  3. Generate a draft, then review its exact recipient and revision.
  4. Try sending before approval: the gate should block it.
  5. Approve, edit the message, and inspect the revoked approval.
  6. Approve the new revision, simulate a send, and follow its explanation graph.

Qwen requires its model runtime and relay. Fixture mode is separate and always labelled. All sends are simulated.
